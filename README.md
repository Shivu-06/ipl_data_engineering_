# IPL Data Engineering Project

## Overview
An end-to-end ETL pipeline built using IPL datasets.

## Tech Stack
- Python
- Pandas
- MySQL
- SQLAlchemy
- PyMySQL
- Matplotlib
- Jupyter Notebook
- VS Code

## Project Workflow

CSV Files
↓
Extract
↓
Transform (Cleaning)
↓
Load into MySQL
↓
SQL Analysis
↓
Visualization
